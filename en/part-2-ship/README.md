# Part 2: Ship

What to check before a vibecoded product meets real users and real attackers. Start with the checklist. The playbook turns its highest-risk security items into fixes and verification steps; the third chapter covers risks specific to AI features and coding agents.

## Chapters

1. [Website Production Readiness Checklist](01-production-readiness-checklist.md) — everything to check before a site goes live: mobile, SEO, forms, performance, security, and deployment, grouped into eight production gates and three severity levels.
2. [Security Remediation Playbook](02-security-remediation-playbook.md) — fixes for the vulnerabilities AI-generated code most often introduces, from exposed API keys to missing authorization checks, organized by the OWASP Top 10:2025, each with detect, fix, and verify steps.
3. [Securing AI Features and Coding Agents](03-securing-ai-features-and-agents.md) — prompt injection, the lethal trifecta, tool permissions, retrieval, MCP servers and skills, and running agents safely.
