# Part 1: Build

Decisions to make before and while an AI agent writes the code: which services to build on, how to keep the agent aligned with what you want, and how to build LLM features of your own.

## Chapters

1. [Stack Decision](01-stack-decision.md) — a compact, opinionated default stack for a solo founder or small team, and when it is worth adding more.
2. [The Holy Trinity + 1](02-holy-trinity-plus-one/README.md) — reusable CONSTITUTION, BRIEF, PLAN, and LOG templates (plus an optional RUNBOOK) that keep an AI coding agent aligned across a project's lifetime.
3. [Working with Coding Agents](03-working-with-coding-agents.md) — what the evidence says, the explore–plan–implement–verify loop, context engineering, testing, review, and deployment with agents.
4. [Building with LLMs](04-building-with-llms.md) — choosing models with your own evaluations, structured output, retrieval, cost, observability, and local models.
