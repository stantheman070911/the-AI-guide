# 第一部：打造

在 AI 代理開始寫程式之前與過程中，需要做的決定：要建立在哪些服務之上、如何讓代理持續對準你想要的東西，以及如何打造你自己的 LLM 功能。

## 章節

1. [技術堆疊決策](01-stack-decision.md)——為個人創業者或小團隊準備的精簡、有主見的預設技術堆疊，以及什麼時候才值得再加東西。
2. [神聖三位一體 + 1](02-holy-trinity-plus-one/README.md)——可重複使用的 CONSTITUTION、BRIEF、PLAN、LOG 文件範本（另有選配的 RUNBOOK），讓 AI 程式代理在專案整個生命週期中保持對齊。
3. [與程式代理協作](03-working-with-coding-agents.md)——證據怎麼說、探索－規劃－實作－驗證的循環、上下文工程，以及與代理一起測試、審查與部署。
4. [用 LLM 打造功能](04-building-with-llms.md)——用你自己的評估選模型、結構化輸出、檢索、成本、可觀測性與本機模型。
