# 第二部：上線

在 vibecoded 產品面對真實使用者與真實攻擊者之前，需要檢查什麼。先從檢查清單開始；修補手冊把其中風險最高的資安項目，展開成修正方法與驗證步驟；第三章則涵蓋 AI 功能與程式代理特有的風險。

## 章節

1. [網站上線準備檢查清單](01-production-readiness-checklist.md)——網站上線前要檢查的一切：行動裝置、SEO、表單、效能、資安與部署，並歸納為八道上線關卡與三個嚴重等級。
2. [資安修補手冊](02-security-remediation-playbook.md)——AI 生成的程式碼最常引入之漏洞的修正方法，從外洩的 API 金鑰到缺少授權檢查，依 OWASP Top 10:2025 分類，每一項都有偵測、修正與驗證步驟。
3. [保護 AI 功能與程式代理](03-securing-ai-features-and-agents.md)——提示詞注入、致命三要素、工具權限、檢索、MCP 伺服器與 skills，以及如何安全地執行代理。
