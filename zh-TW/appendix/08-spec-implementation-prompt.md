# 附錄 H：依規格實作提示詞

一份依產品規格開發的提示詞。代理先讀規格，再著手實作，並標出需要你決定的缺口。

## 使用方式

1. 附上規格，或把它放進儲存庫。[BRIEF 範本](../part-1-build/02-holy-trinity-plus-one/BRIEF.md)是一種可用的格式；可測試的驗收標準讓代理有明確的完成點。
2. 在既有程式碼庫上，先執行[附錄 G](07-codebase-onboarding-prompt.md)，讓代理了解它將修改的程式碼。
3. 把下方區塊貼上作為任務。
4. 回答它標出的模糊之處。接受成果之前，先對照規格檢查它自行做出的決定；[附錄 F](06-pr-review-prompt.md) 可以用來審查結果。

## 提示詞

```markdown
請仔細閱讀附上的產品規格，了解其需求、目標與預期的使用者體驗。充分理解之後，開始實作：緊密遵循規格，並在細節未明確定義之處做出合理的決定。

優先考量乾淨、可維護的程式碼、精緻的使用者體驗與功能的完整性。有系統地推進實作，並標出任何需要釐清的重大模糊之處或阻礙。
```
